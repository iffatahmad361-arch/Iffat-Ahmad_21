# 🇮🇳 India AQI Data Analysis Project

## 📌 Project Overview
This project focuses on analyzing Air Quality Index (AQI) data across different cities in India using Python.

The main objective is to understand air pollution patterns, compare air quality between cities, identify highly polluted and cleaner cities, and generate meaningful insights through data analysis and visualization.

## 🎯 Project Objectives
- Clean and preprocess the AQI dataset.
- Identify and handle missing values and duplicate records.
- Perform Exploratory Data Analysis (EDA).
- Analyze AQI levels across Indian cities.
- Compare city-wise and state-wise air quality.
- Generate graphs and statistical insights.

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook / VS Code
- Git and GitHub

## 📊 Project Workflow

### 1. Data Cleaning
- Checked missing values.
- Removed duplicate records.
- Cleaned column names and text values.
- Handled missing data.
- Exported the cleaned dataset.

### 2. Exploratory Data Analysis
- Examined dataset structure.
- Generated statistical summaries.
- Studied AQI distribution.
- Created visualizations.

### 3. City-wise Analysis
- Identified the top 10 most polluted cities.
- Identified the top 10 cleanest cities.
- Compared average AQI levels.

### 4. Statistical Analysis
- Calculated mean and median AQI.
- Identified maximum and minimum AQI.
- Calculated standard deviation.
- Performed state-wise and city-wise comparisons.
